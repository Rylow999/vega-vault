## Abstract (Borrador)

We present DSCN-G (Dual-State Cognitive Geometry), a unified computational architecture that models cognition as an emergent property of autopoietic hierarchical graphs. The framework integrates: (a) high-dimensional state vectors evolved via stochastic TD-learning; (b) bounded Kuramoto phase dynamics; (c) K parallel information chains with probabilistic transitions; (d) activity-dependent structural plasticity; and (e) O(log N) memory recovery via harmonic resonance.

We establish three formal theorems verified computationally over 200,000 state evaluations (100 independent seeds × 2000 steps): **Theorem 1** (homeostatic fixed point, N_ss* = 4.0 ± 0.0 for α = 5.0, θ_death = 0.10); **Theorem 2** (parametric vector convergence, ‖ω − ω*‖ = 0.038 < β = 0.10); **Theorem 3** (phase convergence rate, p_conv = 0.97). We validate Theorem 1 in a cognitive task: N-back accuracy drops from 89.1% (4-back) to 51.6% (5-back), confirming working memory capacity ≈ 4 items, matching Cowan's (2001) empirical limit.

The **C3 Prediction** (Phase-Hijacking) constitutes the framework's primary differentiating contribution: a falsifiable computational prediction that directional phase perturbation occurs under valence overload, with suggested neurobiological interpretation via gamma-band PLV in S1-aPFC circuitry. **Theorem 7** establishes Φ_proxy scaling O(log N) for fractal circulant graphs, providing an O(K) computable proxy for Φ_IIT's exponential cost.

DSCN-G is the first cognitive framework that: (a) specifies falsifiable quantitative predictions (4±1 items, PLV diff > 0.3, O(log N) scaling), (b) provides open-source simulator for validation, and (c) formally specifies three verified theorems. The ontological position is computational neural correlate (NCC): DSCN-G does not resolve the hard problem of consciousness, but specifies the most formally complete structural-computational correlate available in current literature.

**Keywords:** synthetic cognition, autopoietic graphs, Kuramoto dynamics, TD-learning, working memory capacity, phase-hijacking, integrated information proxy, neural correlates
