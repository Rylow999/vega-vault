# Camino A — Test of fire: MiniSandbox → Sandbox (Minecraft-like)

**Proposed by Luciano 2026-08-03** (not implemented). The only honest test of open-world agency: the agent
gets NO external objectives; purpose emerges from its own homeostasis + curiosity.

## Why it is the real test
- Mazes 10x10 are toys. A sandbox is compositional (combine blocks, build, mine, evade) = exactly the
  Relational Composition (Gap 2) SGM still owes.
- Curiosity global (0036/38/39) needs infinite novelty; in a maze it saturates. In a sandbox eta never
  empties → boredom/exploration become sustained behaviors, not a 40-trial trick.
- Pain/identity get real weight: losing inventory = nodal trauma (0021); death+respawn = identity across
  reset (0034); cold/hunger = homeostatic pain (0033b).
- Internal discourse (0040) finds its reason: no given goal → the agent must keep coherence between
  "quiero explorar esa cueva" (eta), "tengo hambre" (pain), "me dolió la última vez" (trauma).

## Risk (honest)
- Minecraft client is heavy for Android/this env. Mitigation: build a **MiniSandbox** (3D block grid with
  compositional actions: mine/place/evade) that runs on-device without the heavy client. The real client
  is the "test of fire" once hardware exists.
- Biggest risk: in open world the agent becomes a pointless infinite-exploration wanderer. The 0040
  discourse loop is the PRE-REQUISITE brake — order matters: **0040 → MiniSandbox → Sandbox**.
